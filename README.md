# فروشگاه لباس کودک و نوجوان مینی‌مانی (minimani)

فروشگاه آنلاین تخصصی پوشاک کودک و نوجوان ۱ تا ۱۴ سال، ارائه‌دهنده لباس‌های وارداتی و ترک با پارچه‌های نرم، طبیعی و ضدحساسیت.

---

## 🚀 راهنمای راه‌اندازی سریع در سیستم شما (Quick Start)

### پیش‌نیازها:
- **Node.js**: نسخه 18 یا بالاتر (پیشنهادی Node 20 یا 22)
- **npm** یا **pnpm** یا **yarn** یا **bun**

### ۱. نصب وابستگی‌ها (Install Dependencies)
در پوشه پروژه دستور زیر را اجرا کنید:

```bash
npm install
```
یا با bun:
```bash
bun install
```

### ۲. اجرای سرور توسعه (Start Development Server)
```bash
npm run dev
```
سپس مرورگر خود را باز کرده و به آدرس `http://localhost:3000` (یا پورتی که Vite نمایش می‌دهد) بروید.

### ۳. ساخت نسخه نهایی برای تولید (Production Build)
```bash
npm run build
```
فایل‌های کامپایل شده نهایی در پوشه `dist` قرار می‌گیرند و آماده انتشار بر روی هاست، Vercel، Netlify، Cloud Run و... هستند.

## 🖥️ نسخه پیش‌نمایش بدون دامنه (Single-File Preview)

اگر فقط می‌خواهید سایت را **پیش‌نمایش** دهید و هیچ دامنه، هاست یا وب‌سروری ندارید، با یک دستور ساده یک فایل HTML کاملاً مستقل ساخته می‌شود:

```bash
npm run build:preview
```

خروجی این دستور فایل `preview.html` در ریشه پروژه (و یک نسخه کپی در `public/preview.html`) است. کافی است این فایل را **دوبار کلیک** کنید تا در مرورگر باز شود؛ نه به وب‌سرور نیاز دارد و نه به دامنه. تمام کدهای React، استایل‌های Tailwind و فونت‌ها داخل همین یک فایل قرار می‌گیرند.

> در این حالت تصاویر محصولات از اینترنت (Unsplash) بارگذاری می‌شوند؛ اگر عکس‌ها بارگذاری نشوند، به‌جای آیکون شکسته یک جای‌گیر (Placeholder) زیبا نمایش داده می‌شود.

برای ساخت نسخه‌ای که **کاملاً آفلاین** و بدون اینترنت هم کار کند (تصاویر هم داخل همان فایل جای می‌گیرند و حجم فایل بیشتر می‌شود):

```bash
npm run build:preview:offline
```

> فایل `preview.html` که همراه پروژه قرار دارد با همین حالت آفلاین ساخته شده است تا در هر شرایطی (حتی بدون اینترنت) کامل و درست نمایش داده شود. همین فایل در `public/preview.html` هم کپی می‌شود تا دکمه «مشاهده پیش‌نمایش» در پنجره دانلود سورس (داخل خود سایت) و آدرس `/preview.html` همیشه در دسترس باشد.

برای تست این نسخه از طریق یک سرور محلی (اختیاری):

```bash
npm run preview:static
```

## 🛠️ تکنولوژی‌های به‌کار رفته (Tech Stack)

- **React 19**: رابط کاربری سریع و مدرن
- **TypeScript**: امنیت نوع داده و توسعه تمیز
- **Vite**: بیلد سریع و بهینه‌سازی عالی
- **Tailwind CSS v4**: استایل‌دهی مدرن و واکنش‌گرا (ریسپانسیو)
- **Lucide Icons**: آیکون‌های وکتور زیبا
- **Motion**: انیمیشن‌های روان و چشم‌نواز

```text
├── public/                 # فایل‌های استاتیک و عمومی
├── src/
│   ├── components/         # کامپوننت‌های رابط کاربری
│   │   ├── Header.tsx           # نوار بالا، منو، جستجو و سبد خرید

│   │   ├── ProductSection.tsx   # کاتالوگ، فیلترها و مرتب‌سازی
│   │   ├── ProductDetailModal.tsx# جزئیات کامل محصول و انتخاب سایز/رنگ
│   │   ├── CartDrawer.tsx       # پنل کشویی سبد خرید و اعمال کد تخفیف
│   │   ├── CheckoutModal.tsx    # فرم تسویه حساب و ثبت سفارش
│   │   ├── SizeGuideModal.tsx   # جدول راهنمای جامع سایزبندی ۱ تا ۱۴ سال

│   │   ├── AuthModal.tsx        # ورود و ثبت‌نام سریع
│   │   ├── InfoModal.tsx        # درباره ما، قوانین، حریم خصوصی و...
│   │   └── Footer.tsx           # فوتر سایت با راه‌های ارتباطی و مجوزها
│   ├── data/
│   │   └── products.ts     # دیتابیس محصولات با عکس، سایز، موجودی و رنگ
│   ├── utils/
│   │   └── format.ts       # توابع قالب‌بندی اعداد فارسی و قیمت به تومان
│   ├── types.ts            # تعاریف مدل‌های داده (TypeScript Interfaces)
│   ├── App.tsx             # کامپوننت ریشه و مدیریت وضعیت سراسری
│   ├── main.tsx            # نقطه ورود اپلیکیشن React
│   └── index.css           # پیکربندی استایل‌ها و فونت‌ها
├── index.html              # صفحه اصلی HTML
├── preview.html            # نسخه پیش‌نمایش تک‌فایلی (خروجی npm run build:preview)
├── package.json            # مدیریت پکیج‌ها و اسکریپت‌ها
├── scripts/
│   └── build-preview.mjs   # اسکریپت ساخت نسخه پیش‌نمایش تک‌فایلی و آفلاین
├── tsconfig.json           # تنظیمات تایپ‌اسکریپت
├── vite.config.ts          # تنظیمات Vite (توسعه و بیلد اصلی)
└── vite.preview.config.ts  # تنظیمات بیلد نسخه پیش‌نمایش تک‌فایلی
```

## 🎁 امکانات کلیدی فروشگاه
- 🛒 **سبد خرید کامل و تعاملی** با امکان کم/زیاد کردن تعداد و حذف اقلام، محاسبه هزینه پست و تخفیف
- 🎟️ **سیستم کد تخفیف** (کدهای نمونه: `MINIMANI`، `MINI10`، `YALDA`)
- 📏 **جدول راهنمای سایز دقیق** متناسب با قد، وزن و سن کودک
- 🔍 **جستجوی آنی و فیلترهای دسته‌بندی** (نوزادی، دخترانه، پسرانه، اکسسوری، تخفیف‌دار و...)
- 💖 **لیست علاقه‌مندی‌ها** با ذخیره‌سازی محلی (LocalStorage)
- 🚚 **محاسبه هوشمند ارسال رایگان** برای خریدهای بالای ۲ میلیون تومان
- 📱 **طراحی کاملاً واکنش‌گرا** بهینه‌شده برای موبایل، تبلت و دسکتاپ
